# سپهر IKEv2 — کلاینت بومی اندروید (Kotlin + Jetpack Compose)

## ویژگی‌های پیاده‌سازی‌شده
- **اجرای بومی IKEv2/IPsec:** استفاده از `android.net.Ikev2VpnProfile` و `android.net.VpnManager` (اندروید ۱۱ به بالا / API 30+) با `Hostname = IP` و `Remote ID = Domain`.
- **پینگ واقعی هندشیک IKEv2:** کلاس `Ikev2RealPingProber` بسته واقعی `IKE_SA_INIT` (RFC 7296) را روی پورت UDP 500 و 4500 ارسال کرده و پاسخ IKEv2 را تایید می‌کند تا مطمئن باشید سرور واقعاً وصل می‌شود.
- **احراز هویت زنده هنگام ورود:** بررسی نام کاربری، رمز عبور و وضعیت `active` از فایل `users.json`.
- **به‌روزرسانی خودکار لیست سرورها:** در هر بار باز شدن برنامه (`Lifecycle.Event.ON_START`) لیست سرورها مجدداً دریافت می‌شود.
- **مخفی‌سازی کامل اطلاعات حساس:** آدرس IP، دامنه و نام کاربری/رمز عبور تونل در لایه `SecretTunnelSpec` نگهداری می‌شوند و هرگز در UI یا لاگ‌ها نمایش داده نمی‌شوند.

## نحوه ساخت APK
1. فایل ZIP پروژه را از حالت فشرده خارج کنید.
2. پوشه را در **Android Studio (Ladybug یا جدیدتر)** باز کنید.
3. صبر کنید تا Gradle Sync به پایان برسد.
4. یک گوشی اندرویدی (اندروید ۱۱ به بالا) متصل کرده و دکمه **Run** یا منوی **Build > Generate Signed App Bundle / APK** را بزنید.
